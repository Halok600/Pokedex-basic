# 🎮 Pokédex Web App

A simple Pokédex web application built using **HTML, CSS, and JavaScript** that allows users to search for any Pokémon and instantly view its details, including official artwork, ID, height, weight, and type information.

This project was created to practice working with APIs, asynchronous JavaScript, DOM manipulation, and responsive UI design.

---

## 📸 Features

- 🔍 Search Pokémon by name
- 🎨 Display official Pokémon artwork
- 🏷️ View Pokémon ID
- 📏 View height and weight
- ⚡ Display Pokémon types
- ❌ Error handling for invalid Pokémon names
- 🎵 Pokémon theme music included
- ⌨️ Press **Enter** to search instantly

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- PokéAPI

---

## 🚀 How It Works

1. User enters a Pokémon name.
2. JavaScript sends a request to the PokéAPI.
3. Pokémon data is fetched asynchronously.
4. The application displays:
   - Official Artwork
   - Name
   - ID
   - Height
   - Weight
   - Types
5. If the Pokémon does not exist, an error message is shown.
